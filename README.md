# 太陽光見積依頼書メーカー

## 目的
太陽光設備の見積依頼書を入力フォームから作成し、プレビュー表示し、PDF出力（A4縦・高品質テキスト形式）できるWebアプリ。

## 技術要件
- バックエンド不使用
- `index.html` 単体で動作
- CSSとJavaScriptは `index.html` 内に記述
- PDF出力にはブラウザ標準の印刷機能（`window.print()`）を使用（テキストの選択・コピー・検索が可能な高品質ベクターPDFを生成）
- ブラウザ上のみで完結する静的アプリ

## 画面要件
1. **入力フォームエリア**（画面左側）
2. **帳票プレビューエリア**（画面右側）
3. 「PDF出力」ボタン（ブラウザの印刷ダイアログを起動）
4. 「入力リセット」ボタン
- PCでの操作に最適化したレスポンシブデザイン（画面幅が狭い場合は縦並び）

## 帳票プレビュー・デザイン要件
- **用紙サイズ・向き**: A4縦向き（Portrait）に完全最適化
- **ヘッダー・捺印欄**:
  - 帳票タイトル: 「太陽光設備　見積依頼書」 (中央寄せ、下二重線)
  - 右上の日付: 印刷出力日として現在日付を自動表示 (形式: YYYY年 M月 D日)
  - 右上のスタンプ捺印欄: 「担当」「確認」「承認」の3連枠を用意
  - 宛先: 左上に下線付きで配置
- **ビジネス帳票風レイアウト**:
  - Excelで作成された美しいビジネス文書を意識し、フォントはモダンなゴシック体系、すっきりとした下線や細い罫線を使用。
  - **項目6（工事）の自動分割**:
    見本帳票のレイアウトを再現するため、「——自家消費など既設設備がある場合——」という区切り線を挟んで、基本工事（9項目）と既設設備関連工事（3項目）を自動的に分割配置。
  - チェック項目は、チェック済みを「☑」、未チェックを「□」で表現。
- **印刷最適化（2ページ目白紙・見切れの完全防止）**:
  - 印刷時（`@media print`）は入力フォームや操作ボタンを自動的に非表示にし、プレビューエリアのみを印刷。
  - 用紙マージンを `0` にし、高さを `295.5mm` に微調整することで、ブラウザのピクセル丸め誤差による「右端の見切れ」や「不要な2ページ目の白紙出力」を完全に防ぎ、美しいA4縦1ページに固定。

## 入力項目
- **種別**: 新規 / 追加変更 (ラジオボタン)。PDF上では「☑新規 □追加変更」のように表示。
- **宛先**: 1行テキスト。PDF上では「〇〇 様」と表示。
1. **見積依頼番号**: 1行自由記述
2. **住所**: 1行自由記述
3. **工事件名**: 1行自由記述
4. **工期**: 着工日・引渡日 (date input)。PDF上では「YYYY年 M月 D日」で表示。
5. **見積期間**: 1行自由記述
6. **工事**: チェックリスト
   - **基本工事**: 引込工事、受変電設備工事、架台設置工事、通信設備工事、電気配線工事、接地工事、モジュール設置工事、フェンス工事、造成工事
   - *（区切り表示：——自家消費など既設設備がある場合——）*
   - **既設設備工事**: 既設改修・改造工事、既設移設・撤去工事、その他必要な工事
7. **試験その他**: チェックリスト (使用前自主検査、IVカーブ測定、主任技術者費用（工期中）、土地境界確定、除草・ツタ取り、完成図書、産業廃棄物処理、各届け出、住民説明会（必要に応じて）)
8. **工事内容**: 複数行自由記述
    - 初期値: 
      本依頼書は、太陽光発電設備（発電所または自家消費）の建設工事の見積依頼です。
      別紙の項目表および添付資料（配置図等）により見積をお願いいたします。
9. **その他**: 複数行自由記述
    - 初期値:
      ・客先特別仕様がある場合は、資料を添付しますので、見積に反映すること。
      ・海岸より近傍の場合は、必要に応じて主要機器を耐塩塗装とすること。
      （海岸より300m→重耐塩、海岸より301～1000m→耐塩）

## PDF出力・ファイル名自動提案仕様
- **出力方法**: 「PDF出力」ボタンをクリックするとブラウザの印刷ダイアログが起動するため、送信先で「PDFとして保存」を選択して出力します。
- **ファイル名規則**:
  保存時のデフォルトファイル名が **`出力日(yyyymmdd)-工事件名.pdf`** になるよう実装。
  *※JavaScriptで印刷実行時に一時的に `document.title` を書き換えるハックを採用しており、ユーザーが手動でファイル名を入力する手間を省きます（印刷終了後に元のタイトルに自動復帰）。*

## バリデーション
- 見積依頼番号、住所、工事件名が未入力の場合、入力フォーム側に警告メッセージを表示
- 未入力状態であってもPDF出力（印刷）自体は可能
