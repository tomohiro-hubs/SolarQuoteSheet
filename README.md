# 太陽光設備 見積依頼書＆項目表メーカー

本リポジトリは、太陽光発電設備などの建設工事に関連する「見積依頼書」および「項目表」をブラウザ上で作成・プレビューし、高品質なA4縦型PDFとして出力できる静的Webアプリケーションツール群です。

---

## 📂 構成ツール一覧

### 1. 太陽光設備 見積依頼書メーカー (`index.html`)
入力フォームから見積依頼書に必要な情報を記述し、A4縦型ビジネス帳票のプレビューを確認しながらPDFを出力します。

#### 技術要件
- `index.html` 単体で動作（バックエンド不要）
- CSSとJavaScriptは `index.html` 内に記述
- PDF出力にはブラウザ標準の印刷機能（`window.print()`）を使用（テキスト選択・検索・コピーが可能なベクターPDFを生成）

#### 帳票プレビュー・デザイン要件
- **用紙サイズ・向き**: A4縦向き（Portrait）に完全最適化
- **ヘッダー・捺印欄**:
  - タイトル: 「太陽光設備　見積依頼書」 (中央寄せ、下二重線)
  - スタンプ捺印欄: 右上に「担当」「確認」「承認」の3連枠
  - 宛先: 左上に下線付きで配置
- **工事項目（項目6）の自動分割**:
  - 見本帳票を再現するため、「——自家消費など既設設備がある場合——」の区切り線を挟んで、基本工事（9項目）と既設設備関連工事（3項目）を自動的に分割表示。
- **印刷最適化**:
  - 高さ `295.5mm`・印刷余白 `0` に調整し、不要な2ページ目の発生や見切れを完全防止。

---

### 2. 太陽光設備 項目表メーカー (`items.html`)
全42行の項目、内容、備考を入力し、分担範囲（エナジオ・請負者）をチェックボックスで指定して、A4縦型1ページの美しい表を出力します。

#### 技術要件
- `items.html` 単体で動作（バックエンド不要）
- 双方のツールをシームレスに行き来できるよう、画面上部に **相互ナビゲーションリンク** を完備。

#### 画面・機能要件
- **入力フォーム（左側）**:
  - スクロール可能なテーブル形式で、全42行の「項目」「内容」「備考」を1行でスマートに入力可能。
  - 各行の「エナジオ」「請負者」チェックボックスで担当範囲を割り当て。
- **初期データの自動設定**:
  - ユーザーの入力の手間を省くため、ご提示いただいた見本に記載されている **No.1〜27までの全デフォルトデータ** が最初から初期値として入力されています。
- **帳票プレビュー（右側）**:
  - A4縦の帳票上に、入力されたテキストおよびチェック（☑ / □）をリアルタイムで同期して表示。

#### デザイン＆印刷最適化要件
- **厳密なA4縦1ページへの収まり**:
  - 全42行＋ヘッダー2行＝合計44行の長大なテーブルを、A4縦1ページ（高さ `295.5mm`・印刷余白 `0`）の中に完璧に収めるため、印刷用CSSでフォントサイズを `8pt`（約10.5px）、行の高さ（height）を `17.5px` に厳密に固定。
  - テキストが長くなってセル内で改行され、レイアウトが崩れたり2ページ目に溢れたりするのを防ぐため、`white-space: nowrap; overflow: hidden; text-overflow: ellipsis;` を適用。
  - 列幅は、テーブル結合セル（colspan）の干渉を受けないよう、`<colgroup>` タグを用いて各列（エナジオ・請負者それぞれ9%）を物理的に一括制御しています。

## ⚡ 超強力な自動保存（オートセーブ）機能 (共通)
見積依頼書 (`index.html`) と項目表 (`items.html`) の両方に、ブラウザ標準のキャッシュ機構（`localStorage`）を用いた **自動保存＆自動復元ロジック** を搭載しています。

1. **ページを行き来してもデータが消えない**:
   見積依頼書と項目表をどれだけ行き来しても、入力中のデータは自動で保存され、元のページに戻った際に100%完全に復元されます。
2. **ブラウザを閉じてもデータを保持**:
   誤ってブラウザを閉じてしまったり、PCを再起動して後日開いた場合でも、入力途中のデータはそのまま保持されます。
3. **リセット連動**:
   各ページにある「入力リセット」ボタンをクリックすることで、保存されているローカルキャッシュも綺麗に削除され、初期状態に戻すことができます。
4. **超リアルタイムプレビュー**:
   自動保存の連動に伴い、文字を入力したその瞬間に右側のプレビューが滑らかに同期して自動更新される、非常に快適なUXを実現しています。

## 📄 PDF出力・ファイル名自動提案仕様 (共通)
両ツールとも、以下の便利な印刷・保存ハックを実装しています。
1. **出力方法**: 「PDF出力」ボタンをクリックするとブラウザの印刷ダイアログが起動するため、送信先で「**PDFとして保存**」を選択して出力します。
2. **ファイル名自動生成**:
   - 見積依頼書 (`index.html`): **`出力日(yyyymmdd)-工事件名.pdf`**
   - 項目表 (`items.html`): **`出力日(yyyymmdd)-項目表.pdf`**
   *※印刷実行時にJavaScriptで一時的に `document.title` を書き換えることで、保存時のデフォルトファイル名をブラウザに自動提案させます（印刷終了後は元のタイトルに自動復帰）。*

## 🛠 動作確認方法
1. 本リポジトリのディレクトリでローカルサーバーを起動します。
   ```bash
   python -m http.server 8080
   ```
2. ブラウザで以下のURLを開きます。
   - 見積依頼書: `http://localhost:8080/index.html`
   - 項目表: `http://localhost:8080/items.html`
